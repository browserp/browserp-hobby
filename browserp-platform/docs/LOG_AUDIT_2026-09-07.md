## Confirmed PostgreSQL finding

Fifteen errors were **“A current verified player observation is required”**, with context identifying `public.service_refresh_cfx_snapshot(text,text,boolean,integer,integer,timestamptz)`, line 5 at `RAISE`. Their first occurrence was **6 September 16:12:02.511 UTC**, and their last was **7 September 13:47:02.974 UTC**.

That guard checks both observation values and timestamps. The application and SQL share the five-minute past / one-minute future Cfx freshness window. An observation can pass application validation and expire before the database transaction starts; the log context confirms the rejecting function but does not establish the precise rejected value or clock drift. The five-minute rule remains unchanged.

A confirmed application defect previously caught these rejected saves inside the upstream-source error handler. If the subsequent unavailable marker succeeded, the worker could report source unavailability without recording a failed processing attempt. Local fix **`844633e8295b94e4248df7541aaa1cb8b5847a7c`** separates upstream validation from persistence for Cfx and Minecraft, preserving genuine source failures while allowing rejected saves to reach the worker failure counter. It does not make stale observations fresh or claim to remove every upstream failure. The source-refresh batch passed a reported **958 local gate checks**; the combined release, including the separate Roblox integration correction, was still being prepared when this document was drafted. This document does not claim that successor is deployed.

The remaining PostgreSQL error was a syntax error near `limit100` at **7 September 13:38:39.400 UTC**, consistent with the manual diagnostic query typo encountered during this investigation. It is not evidence of an application-generated query defect.
